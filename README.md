# AnimeAI 🎌

An AI-powered anime recommendation app that helps you discover new anime based on your mood, taste, and preferences.

## Features
- **Mood-based recommendations** — Select a mood or describe what you're looking for
- **Anime DNA** — Input 3 anime you like and get a personalized taste profile with recommendations
- **Character Chat** — Chat with iconic anime characters (Naruto, Light Yagami, Levi, Goku, Luffy, Eren)

## Tech Stack
- **Streamlit** — UI framework
- **OpenAI API** (GPT-4o-mini) — AI recommendations and character chat
- **AniList GraphQL API** — Anime data
- **Pandas** — Data processing
- **Plotly** — Data visualization
